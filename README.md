📝 Django To-Do List Application
A simple and efficient To-Do List web application built with Django that allows users to create, update, and manage daily tasks.

🚀 Features
User authentication (Register, Login, Logout)
Create new tasks
Update existing tasks
Mark tasks as completed
Delete tasks
Simple and responsive UI
Secure data handling using Django ORM

🛠️ Technologies Used
Python
Django
SQLite (default database)
HTML, CSS, Bootstrap
Django Templates

⚙️ Installation & Setup
Clone the repository
git clone https://github.com/Darlitso/django-todo-list.git
cd django-todo-list

Create a virtual environment
python -m venv venv
source venv/bin/activate   # On Windows: venv\Scripts\activate

Install dependencies
pip install -r requirements.txt

Apply migrations
python manage.py migrate

Run the development server
python manage.py runserver

Open in browser
http://127.0.0.1:8000/


🧪 Usage
Register or log in to your account
Add tasks you want to complete
Edit or delete tasks
Mark tasks as completed once done
